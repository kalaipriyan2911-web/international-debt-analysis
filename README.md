# International Debt Analysis System Using Python, SQL, and Power BI

## 📌 Project Overview
This project analyzes international debt data using Python, Exploratory Data Analysis (EDA), SQL, and Power BI. It explores country-level records, debt indicators, and missing data to support data-driven understanding of international debt information.

## 🎯 Objectives
- Clean and prepare international debt data.
- Perform Exploratory Data Analysis (EDA) using Python.
- Analyze debt records using SQL queries.
- Visualize debt indicators using Power BI.
- Present findings through a dashboard.

## 🛠️ Tools & Technologies
- **Python** – Data processing and analysis
- **Pandas** – Data cleaning and manipulation
- **EDA** – Exploring records, indicators, and missing values
- **SQL / TiDB Cloud** – Querying and analyzing data
- **Power BI** – Dashboard and visualizations
- **GitHub** – Project version control and sharing

## 📊 Dataset
The project uses international debt data and supporting metadata files, including country information, series metadata, and country-series mappings.

## 🔎 Project Workflow
1. Load the dataset using Python.
2. Inspect rows, columns, and data quality.
3. Identify and remove duplicate records.
4. Explore missing values and country-level records.
5. Run SQL queries for record counts and debt indicator analysis.
6. Build a Power BI dashboard for visualization.

## 📈 Dashboard
The Power BI dashboard presents debt-indicator visualizations and comparisons for the selected country and years.

## 📁 Project Files
- Python notebook (`.ipynb`)
- SQL analysis (`international_debt_analysis.sql`)
- Project report (`.docx`)
- Power BI dashboard (`.pbix`)

## ⚠️ Note
Missing values are treated as unavailable data and should not automatically be interpreted as zero. Aggregated values across different debt indicators may not represent a country's actual total debt.
